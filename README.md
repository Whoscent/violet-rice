✨ Tentang Repo Ini
violet-rice adalah kumpulan dotfiles personal saya untuk Artix Linux. Tema ini berfokus pada gradien warna violet-to-pink pastel yang mulus, dikombinasikan dengan pemandangan alam yang muted dan aesthetic. Didesain agar nyaman dilihat berjam-jam di depan layar.

🚀 Fitur Menonjol
🎨 Seamless Gradient Prompt: Konfigurasi starship.toml khusus dengan gradien 7 warna dari ungu gelap hingga pink pastel.
🌾 *Scenic GRUB Theme: Sesuaikan set $wallpaper di config WM-mu ke lokasi file tersebut.
📜 Cara Import / Menggunakan Dotfiles Ini
Copy file konfigurasi
Pindahkan folder atau file yang kamu butuhkan ke direktori ~/.config/ di sistemmu. Contoh untuk Starship:
bash

mkdir -p ~/.config
cp -r starship ~/.config/
(Pastikan aplikasi seperti Waybar, Rofi, dan Cava sudah terinstall di sistemmu sebelum meng-copy confignya).
Install Font
Pastikan kamu menginstall font pixel/nerd berikut agar simbol dan teks terlihat sempurna:
Monocraft
PixelHallfeticaJP10P
JetBrainsMono Nerd Font (Sebagai cadangan)
